# HOSTING — Modular Knowledge & Outcome-Driven Execution Standard
Candidate only. Effective only after independent acceptance, exact A0 merge approval and verified main/CI. No new runtime rights. [Core](../AGENTS.md) · [Workflow](AGENT_WORKFLOW.md) · [Lifecycle](DATA_LIFECYCLE_CONTEXT.md) · [Security](REPOSITORY_SECURITY.md).

## Documentation architecture
Use stable unique document IDs, subject INDEX.md or existing README, independent topic files and reciprocal index/component links; cross-topic links only for actual dependencies. Metadata: id, status, owner, parent, related, updated_at, supersedes when applicable; reuse existing schema and lifecycle, no new database. Preserve immutable historical refs; no bulk renaming or rewriting. Canonical rule definitions remain in the relevant module; other files link, not restate. Core plus actual role and task always read; mandatory safety sources triggered by operation remain full reads. Reuse only valid complete pinned sources under MSC.

Soft Unicode character budgets (target/review threshold): core 2000/3000; index 1500/2500; startup role 1000/1500; topic rule 3000/5000; strategy 4000/6000; assignment spec 2000/3500; detailed task 4000/8000; large-file summary 600/1000; handoff 600/1000. Roadmaps, matrices and full capability CVs scale by genuine scope. Never cut safety or acceptance to fit. Explain exceptions. Measure Unicode characters and UTF-8 bytes separately, not tokens.

## Planning architecture
PLAN = strategy, objective, organization and scope; ROADMAP = milestones/order/dependencies; WORK_ITEMS = linked stable IDs and aggregate state; ASSIGNMENT_MATRIX = linked IDs, candidate 1/2 (more if qualified), dependencies and derived status; tasks/<ID>.md = outcome, inputs, acceptance and execution specification (or pinned dispatch spec for complex work). Index links each; task links back to work item; matrix links task, not duplicated requirements. One canonical aggregate state maintained by Coordinator; agent writes only result/evidence section within granted write-set. DONE/READY/WAITING/BLOCKED textual status plus optional visual distinction; never rely on color alone. Candidate rank is not actual assignment. At least two qualified candidates if available, else NO_QUALIFIED_ALTERNATIVE. Verify session capability, capacity, rights, cost, reviewer independence. A0 is owner authority, n8n engine not autonomous assignee.

## Capability profiles
Short startup profile and full CV linked from agent index: identity, role/environment, demonstrated strengths, weaknesses, fit/nonfit, plugins connected/available/unknown, skills verified/available-to-install/conditional, tools/runtime, cost, capacity, evidence/date and freshness. VERIFIED, REPORTED, AVAILABLE_UNTESTED, BLOCKED, UNKNOWN distinguish actual evidence from advertising; historical proof not current session permission. No new installation or activation for inventory.

## Canonical controls
B1/B4: [Execution](execution.md); B2/B3: [Dispatch](dispatch.md); B6: [Handoff](handoff.md); B5: this standard (below); evidence and QA: [Evidence](evidence.md); lifecycle/metadata/retention: existing Lifecycle protocol; MSC: Core. Candidate replaces corresponding old clauses only after full review, not parallel authority.

B5 — A large file has a short Summary stating purpose, effectiveness, sections relevant to task, rights boundary and links. Summary is a navigation aid, never substitute for mandatory clauses. For immutable large Gate B source, external index with section anchors and pinned version serves this function without rewriting it.

## Verification
Preserve security, reserved rights, independent QA, KNG snapshot/release semantics, history and validators. No task/report/evidence in CATALOG. Compare identical representative task read sets in characters/bytes, target >=30% reduction without quality loss. Independent A/B T1 versioned appraisal, T2 ACK attribution, T3 partial blocker; same model/task/data/tools/rights, separate sessions, log correctness, reminders, reading and time. Missing telemetry or independent execution = NOT_RUN/PARTIAL. No author simulation as independent evidence. One draft PR, no merge without owner approval.
