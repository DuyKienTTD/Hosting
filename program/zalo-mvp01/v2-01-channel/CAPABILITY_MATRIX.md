## SDK và vận hành

- Subiz có REST và tài liệu webhook. Tìm theo trang developer, SDK và GitHub với từ khóa Subiz, đối chiếu [Widget v4](https://widget.subiz.com/) (26/11/2026). Chưa tìm được SDK server công khai hỗ trợ kênh Personal cụ thể. Dùng HTTP chuẩn theo phiên bản route trong tài liệu.
- [`node-zalo-bot`](https://docs.zaloplatforms.com/zalo-bot) được Zalo liệt kê. Đã cài và chạy SDK 0.1.6 với server loopback. Xem [bằng chứng](mock/EVIDENCE.md). Giao diện web Subiz chỉ có thể đánh giá theo tài liệu ở lượt chưa đăng nhập, chưa đo reconnect, chống trùng và ổn định selector.
- zca-js ghi MIT tại manifest và cảnh báo có thể vô hiệu hóa tài khoản. Điều khoản và bài trợ giúp Zalo mô tả rủi ro khi dùng phần mềm bên thứ ba thiếu chấp thuận. Chỉ khảo sát công khai.
